One newspaper front page that sums up the world's news of Monday
23 November 2026: the COP31 climate talks collapsing with no deal in
Antalya, Democrats clinching 258 House seats, sea drones sinking a Russian
warship in Benghazi, a deadly factory fire in Indonesia, strikes across the
Kyiv region, the Geneva peace talks, and Verstappen's wild Las Vegas win.

`draw.py` draws `entry.png` (1024×1024) from scratch with Pillow — every
text block is measured first and the script fails rather than overflowing.
`main.ts` copies the committed image to the output directory.
